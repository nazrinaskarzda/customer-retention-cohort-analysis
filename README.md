# Customer Retention Cohort Analysis

A concise cohort analysis examining how customer retention changes over the months following their first purchase.

## Analiz haqqında

Müştərilər ilk alış etdikləri aya görə cohort-lara bölünüb və sonrakı aylarda alışa davam edən müştərilərin faizi hesablanıb.

## Əsas müşahidə

Əksər cohort-larda ilk aydan sonra retention göstəricisi azalır. Bununla yanaşı, bəzi aylarda müştərilərin yenidən aktivləşməsi nəticəsində retention faizində artımlar müşahidə olunur.
